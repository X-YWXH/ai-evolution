## 📌 项目简介

本项目旨在系统性地梳理与记录**人工智能（AI）自 1950 年代萌芽至今的技术演进全貌**。涵盖核心里程碑事件、关键算法范式突破、代表性学术论文、工业界代表模型及对未来通用人工智能（AGI）与具身智能的思考。

## 🧭 技术演进时间轴

```
1950s               1980s               2012                2017                2022                2024+
  |                   |                   |                   |                   |                   |
[图灵测试 / 达特茅斯]  [专家系统 / BP算法]   [AlexNet 深度学习爆发] [Transformer 诞生]  [ChatGPT 生成式AI]  [Agentic / 具身智能]
  |                   |                   |                   |                   |                   |
  +-- 符号主义与探索    +-- 统计学习与连接主义 +-- 算力+大数据觉醒   +-- 统一架构奠基    +-- 基础模型范式    +-- 复杂推理与自主决策
```

### 章节索引

1. [🏛️ 第一阶段：经典探索时代 (1950s - 1980s)](timeline/01-classical-era.md)
   - 图灵测试与达特茅斯会议的诞生
   - 感知机模型与早期神经网络的第一次寒冬
   - 基于规则的专家系统与知识工程
2. [📈 第二阶段：统计学习与机器学习黄金期 (1990s - 2010)](timeline/02-machine-learning-era.md)
   - 统计学习理论崛起：支持向量机 (SVM)、随机森林、Boosting
   - 反向传播（BP）算法复兴与浅层神经网络
   - 自然语言处理早期探索与统计机器翻译
3. [🔥 第三阶段：深度学习革命与感知突破 (2011 - 2020)](timeline/03-deep-learning-revolution.md)
   - 视觉分水岭：AlexNet、VGG、ResNet 席卷 ImageNet
   - 强化学习高光时刻：DeepMind 与 AlphaGo 系列
   - 生成模型突破：生成对抗网络 (GAN) 与 VAE
   - 架构基石奠定：Transformer 架构的划时代诞生 ("Attention Is All You Need")
4. [⚡ 第四阶段：大模型与生成式 AI 狂潮 (2020 - 2024)](timeline/04-llm-and-generative-ai.md)
   - GPT 系列与 ChatGPT 引爆全球生成式 AI
   - 开源大模型生态崛起：LLaMA 系列、Mistral、DeepSeek、Qwen
   - 多模态模型融合：Gemini、Claude、GPT-4o、扩散模型（Sora、Flux 等）
5. [🤖 第五阶段：推理进阶、自主智能体与具身智能 (2024 - 未来)](timeline/05-agentic-and-embodied-ai.md)
   - 慢思考与强化推理：OpenAI o1 / o3、Gemini Flash Thinking、DeepSeek-R1
   - 自主智能体（Agentic AI）：工具调用、多智能体协同（MCP 协议、自主编程）
   - 物理世界映射：具身智能（Embodied AI）、人形机器人与自动驾驶统一大模型
